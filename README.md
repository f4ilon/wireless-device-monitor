# Wireless Device Monitor (WDM)

Приложение для Windows, предназначенное для обнаружения беспроводных устройств и мониторинга их состояния, в первую очередь — уровня заряда аккумулятора.

Проект разрабатывается на **Rust** с использованием HID-интерфейсов Windows.

## Цели проекта

- Автоматическое обнаружение беспроводных устройств.
- Получение уровня заряда аккумулятора.
- Поддержка устройств разных производителей.
- Расширяемая архитектура для добавления новых протоколов.
- Минимальное использование системных ресурсов.

## Технологии

| Технология | Назначение |

| Rust | Основной язык разработки |
| hidapi | Взаимодействие с HID-устройствами |

## Поддерживаемые устройства

На текущем этапе исследуется следующая конфигурация:

| Компонент | Значение |
|---|---|
| Мышь | Lunacy x Honkai: Star Rail |
| Подключение | 2.4 GHz |
| Производитель приёмника | Compx |
| VID приёмника | `0x3554` |
| PID приёмника | `0xF53C` |
| HID Usage Page | `0xFF02` |
| Report ID | `0x08` |
| Команда | `0x04` |

**Важно:** совместимость подтверждена экспериментально для указанного приёмника. Поддержка остальных устройств Compx и других производителей пока не подтверждена.

## Получение заряда аккумулятора

Приложение отправляет HID-команду USB-приёмнику и анализирует полученный ответ.

Пример полученного ответа:

```text
08 04 00 00 00 02 5A 00 0F A1 00 00 00 00 00 EF 58
```

Из ответа извлекается байт с индексом `6`:

```text
Raw battery byte: 0x5A
Battery decimal: 90
Battery percent: 90%
```

Значение проходит дополнительную проверку: ожидаемый формат ответа, идентификатор отчёта и контрольная сумма.

Точность и шаг изменения показаний ещё требуют проверки на реальном устройстве. Значение, полученное от приёмника, может быть округлено прошивкой.

## Установка и запуск

### Требования

- Windows 10 или Windows 11.
- Установленный Rust (через [rustup](https://rustup.rs/)).
- USB-приёмник подключён к компьютеру.

### Запуск

Клонируйте репозиторий:

```bash
git clone <repository-url>
cd wireless_monitor
```

Запустите приложение:

```bash
cargo run
```

Для сборки исполняемого файла:

```bash
cargo build --release
```

Готовый файл появится в:

```text
target/release/wireless_monitor.exe
```

- Отслеживание изменения заряда.
